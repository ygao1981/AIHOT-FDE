【FDE 实战领域术语与证据写法】

- FDE = Forward Deployed Engineering（面向客户现场、紧贴业务交付的工程实践）；FDE Engineer 是驻场/前线交付工程师。不要误译成全盘加密（Full Disk Encryption）。
- PoC = 概念验证；Pilot = 试点；Production = 生产环境。三者不等价。“计划部署/演示/试点”不能写成“已投产”。
- RAG = 检索增强生成；Agent = 智能体；MCP = 模型上下文协议；API = 应用程序接口；ETL = 数据抽取转换加载。
- ROI = 投资回报率；TCO = 总拥有成本；UAT = 用户验收测试；SLA = 服务级别协议；SOP = 标准作业程序。
- 企业实施常见上下文：ERP、MES、WCS、WMS、PLC、OPC UA、SSO、RBAC、私有化部署、灰度发布、回滚、日志与审计。缩写保持原样，首次出现时可补中文解释。
- Palantir AIP、Microsoft ISE、Anthropic Claude、LangGraph、Dify、DeepSeek 等专有名词、产品名和版本号按原文保持，不为营销而添加“首创/革命性”。
- 所有日期、货币、请求/输出 token、单位、部署规模、工时、准确率和性能数字必须在原文有对应。严禁把估算写成真实结果。
- 须区分客户披露、厂商自述、作者推测与第三方复测；没有基线和测量方法的百分比不可当成已验证提升。
- 代码、JSON 字段、API 地址、命令与 URL 保持准确，不改变内容。
