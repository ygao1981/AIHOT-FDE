# 更新记录

## 2.1.0 — 2026-11-22

- 根据 T3 Code 执行链审查，保留独立轻量架构，不复制 T3 源码、不新增运行依赖。
- 入队持久化后唤醒，繁忙期间通知合并；单消费者连续处理，采集与分析独立推进。
- 达到额度或暂停时停止本轮消费；自动补队扣除已用尝试和现有排队，避免持续堆积。
- 人工修订已有正文后保留人工选择分析，不沿用旧的自动准入资格。
- 新增外部脚本收录客户端：默认只收录，显式 --analyze 排队，状态查询与可恢复错误信息。
- Windows 原生 exe / 官方 npm 入口适配、最小环境、精确进程树终止；分析和 doctor 共用边界。
- 新增 Windows CI，假 CLI 使用官方 npm 包目录结构，验证跨平台真实子进程行为。
- 更新 checkpoint、T3 取舍、架构、Windows、外部接入、运维、模型说明、部署和二次开发提示词。

SQLite schema 仍为 user_version=1，无数据迁移；默认模型、采集、自动分析仍关闭。原有资料、个人笔记、尝试账本和预算语义保留。实际通过环境与未验证项以 VALIDATION 为准。

## 2.0.0 — 2026-11-20

新增独立的个人 FDE 研究入口，运行于 `fde-workbench/`。

- Node + SQLite，私有登录，一进程串行任务，无单独数据库服务。
- 核验 27 个来源入口，首批启用 9 个；自动、观察、人工和停用状态分开。
- RSS/Atom 和静态列表采集、来源日期、正文提取、规则筛选与 URL 去重。
- 官方 Responses API 或官方 ChatGPT 登录 Codex CLI，默认关闭，显式选择。
- 持久化次数、API 预算预留、配置感知缓存、失败暂停与人工重试。
- 原文证据、阶段依据、研究笔记、选题进度和 Markdown 导出。
- 完整 checkpoint、来源审计、模型用量、部署、运维和 Codex 接手文档。

旧版 AIHOT/FDE 公开站点代码仍保留，不自动迁移其 PostgreSQL 数据。真实账号、目标 VPS 和容器验收状态见 `docs/VALIDATION.md`，不能从版本号推断这些检查已完成。
