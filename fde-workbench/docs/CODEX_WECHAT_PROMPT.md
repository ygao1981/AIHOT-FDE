## 二、先验收零模型路径

保留既有访问口令和 CLI 登录目录，升级开始保持：

```text
FDE_COLLECT_ENABLED=false
FDE_ANALYSIS_ENABLED=false
FDE_AUTO_ANALYZE=false
FDE_DAILY_LIMIT=5
FDE_EDITORIAL_MAX_OUTPUT_TOKENS=4500
```

`FDE_EDITORIAL_MAX_OUTPUT_TOKENS` 是 API 写作输出上限；Codex CLI 不以它保证硬 token 上限。不要因此接入付费 API 或更改账号。

在新版本的 `fde-workbench/` 安装锁定依赖，执行 `npm.cmd ci --ignore-scripts`、`npm.cmd run check`、`npm.cmd test`、`npm.cmd audit --omit=dev`。验证新建副本的迁移与备份回滚，不在正式库做破坏性故障试验。

启动后进入“公众号草稿”。选一篇已经成功分析且有原文证据的真实资料，点击零模型素材稿。核对：

1. 私人笔记和整篇原文没有自动混进写作输入。
2. 可以改标题和段落，保存后重启仍在；同资料同角度重复创建复用草稿，不覆盖人工编辑。
3. 纯文字和图文两种版本的事实正文一致，切主题、预览、保存和下载均不新增 attempts。
4. 排版包中的 TXT、Markdown、HTML 和 PNG 能实际打开，中文不缺字、不重叠，长标题/要点不裁切。PNG 由本地程序绘制，不调用图片模型或远程图床。
5. 未保存编辑不会被轮询、切换或延迟响应覆盖；两个窗口保存冲突应提示，不能丢字。
6. 退出后草稿接口和预览仍需鉴权，页面没有把原始 JSON、访问口令和模型日志展示给用户。

素材稿只是可编辑材料，不能宣称已经完成 AI 写作。模型关闭时也要能完成这整条验收。

## 三、在现有总上限内测试 AI 写作

本项目允许滚动 24 小时内最多 **5 次真实模型尝试，分析与写作合计**；失败、unknown 和可能已发出的请求也计入。不另开 5 次写作额度，不重置数据库，不改时间，不绕过研究台直接启动 CLI 写稿来规避账本。

先读取实际剩余次数。没有剩余时，完成全部离线测试并报告下一次可用时间；不能当场重复调用。存在剩余且本地检查通过时，可按本提示直接开启现有 codex provider 的人工模型任务，无须每篇再次申请。保持自动采集与自动分析关闭。

先用已分析的一篇资料安排 **一次公众号 AI 写作**。不重新分析它，不为文字版和图文版各写一次。检查新回执类型为写作，原研究卡不变，输入来自研究快照，模型只返回正文结构，没有命令、文件、网页或图片工具活动。CLI 的已验证非终止 notice 不能误判成工具执行；真正工具和未知事件仍应中止。

人工核对内容：符合《半理性半烟火》的短句、克制、场景化规则；没有编造“我的客户”“我昨天开会”等经历；事实、作者自述、编辑判断和建议分开；引文和编号有效；不把试点、局部上线或阶段未知改成全面生产部署；数字没有新增或扩大；正文截断与验证限制仍保留。

再确认重复生成命中同一稿，修改保存、主题切换和两种导出没有新增请求。剩余次数可用于不同角度或多资料写作测试，优先把错误分支放进假 CLI 测试。若出现 unknown，保留回执并暂停；先查明原因再决定明确重试，不自动重发，也不切 API。
