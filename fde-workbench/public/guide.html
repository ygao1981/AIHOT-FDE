使用说明

先看今天发现了什么，再核对原文、整理研究卡，把值得写的观点做成公众号草稿。

启动与登录

  1. 在 Windows 桌面双击「FDE 研究台」，等待浏览器打开。如果浏览器没有自动打开，点下方链接。
  2. 输入部署时设定的研究台访问口令。口令在启动目录的 .env 中由部署者管理。

打开研究台

读今日研究

  1. 打开研究台先看「今日研究」。新发现的讨论、当日发布的原文、当日发现的历史资料分别计数。原文日期不明时，打开出处核查。
  2. 用「资料类型」切换国内或海外实践、工程方法、官方认证和伙伴政策。点「排序依据与出处」核查原文及互动数据。有研究卡时可直接打开。
  3. 读完可收藏、标为方案素材或加入公众号选题。点「更多反馈」，可记录偏理论、推广、重复或不相关。再点一次能撤销。已有资料的选题也可以从研究库的「已选题」查看。
  4. 用日期选择器查看往日发现。导出 Markdown 时沿用选中的资料类型，上方数字始终按整天计算。在「研究偏好与推荐权重」可编辑调研、报价、成本、验收和复用等方向。

打开今日研究

发现线索

  1. 打开「发现线索」。可用日期、积分和评论数在 Hacker News 搜索。在「HN 主题订阅」设置关键字、检查间隔，可立即检查。定时采集开启时，启用的主题和选中的 GitHub 仓库会自动更新。
  2. 在「X 原生搜索」选主题或重点作者，用自己的浏览器查看结果，再粘贴帖子链接、摘录和工程原文。
  3. 在「线索池」核对各个讨论引用的是不是同一篇原文。找到原文后点「关联原文」，再按需要点「收录工程原文」。互动数据缺失会显示未知。

三个渠道的搜索、初筛和保存不使用模型额度。定时跟踪 GitHub 仓库需同时开启定时采集。网页上的 GitHub 讨论区链接可直接打开。

在「信源」展开腾讯研究院、腾讯云 ADP、腾讯 WorkBuddy 或 FDE 能力标准的「重点资料」。可直接阅读核对过的原文，或点「收录」预填链接。考纲和伙伴政策供人工查阅，报考与申报在腾讯云官方页面完成。

打开发现线索

收录、分析与整理

  1. 点「导入资料」并填原文链接。如果网页读不全，用「补充正文」粘贴有权使用的正文，保留日期、具体数据和适用条件。
  2. 在「分析进度」筛选「待分析」，选择一篇点「AI 分析」。完成后打开「查看研究」，核对引文、数字和部署阶段。
  3. 保存个人笔记。在「选题进度」筛选「待整理」。符合条件的研究卡可点「整理素材」。核对完成后手动点「标为已整理」。
待分析
已收录，尚未安排模型生成研究卡。
待整理
还需要人工核对原文、归纳要点或决定用途。已分析的资料也可以待整理。
已整理
你已核对并手动标记。之后再决定是否列入选题。

在「信源 → 采集范围与条数」设置最近几天和每天最多新增几篇。默认采集最近 30 天（含今天），每天最多新增 50 篇。重复资料和手动导入不占采集条数。

点「检查信源更新」即可检查已启用的来源。日期超出范围或不明的资料可手动导入。自动分析关闭时，采集不会启动模型。

看英文资料的译文

在英文资料详情展开「查看中文译文」。点「AI 翻译成中文」会使用一次模型任务，生成后再次查看会复用已保存的译文。若只收录了订阅摘要，译文也只覆盖摘要。引用时回到英文原文核对。

写稿、排版与导出

  1. 进入「公众号草稿」，选 1–3 篇有原文证据的研究卡，填写作角度。用「整理素材稿」汇总，消耗 0 次模型额度。也可以点「AI 写作」安排一次任务。
  2. 改标题和正文，标清来源转述、我的解读、行动建议，点「保存并更新预览」。如果别的窗口已保存新版本，先保留本页需要的文字，再重新载入并合并。
  3. 切换「纯文字版」或「图文版」，主题可选「清爽白纸」和「深色卡片」。选「复制文字版排版」或「下载两版素材包」。包内有 TXT、Markdown、两版 HTML 和图文使用的 PNG。
  4. 在微信公众平台粘贴正文，按图文版的位置上传本地 PNG，手机预览确认后由你发布。发出后可在研究台手动标为「已发布」。

模型额度与排查

手动分析、翻译和写作由你根据账号用量决定。在「用量 → 自动分析额度」可设置滚动 24 小时内的自动尝试上限，默认 5 次。

阅读、笔记、整理素材稿、保存、换主题、复制和下载均不消耗模型额度。用完全相同的资料、角度和配置再次提交写作，会复用原稿及人工修改。

AI 按钮不可用
先到「用量」查看启用状态。模型开关由部署配置管理，开启后重启研究台才生效。
自动分析已满或排队
可在「用量」查看自动次数与上限。对队列中的一篇资料，点「改为手动分析」可以手动安排。
任务未完成或结果未知
先核对账号和用量，再到「用量」恢复处理。未知任务不会自动重发，明确重试会消耗新次数。

打开用量

备份与停止

资料库默认在运行目录的 .data。在 fde-workbench 目录用 Node 24 环境运行 npm.cmd run backup，将资料、草稿、私人笔记和用量回执备份到资料目录下的 backups。

保存当前编辑后，在研究台运行窗口按 Ctrl + C 停止。只关浏览器标签页，研究台会继续运行。
