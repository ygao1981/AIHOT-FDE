使用说明

从收录一篇案例开始。核对证据、整理研究卡，再把值得写的观点做成公众号草稿。

本页目录

启动与登录

  1. 在 Windows 桌面双击「FDE 研究台」，等待浏览器打开。如果浏览器没有自动打开，点下方链接。
  2. 输入部署时设定的研究台访问口令。口令在启动目录的 .env 中由部署者管理。

打开研究台

收录、分析与整理

  1. 点「导入资料」并填原文链接。如果网页读不全，用「补充正文」粘贴有权使用的正文，保留日期、具体数据和适用条件。
  2. 在「分析进度」筛选「待分析」，选择一篇点「AI 分析」。完成后打开「查看研究」，核对引文、数字和部署阶段。
  3. 保存个人笔记。在「选题进度」筛选「待整理」。符合条件的研究卡可点「整理素材」。核对完成后手动点「标为已整理」。
待分析
已收录，尚未安排模型生成研究卡。
待整理
还需要人工核对原文、归纳要点或决定用途。已分析的资料也可以待整理。
已整理
你已核对并手动标记。之后再决定是否列入选题。

在「信源」可以查看或启停固定来源。部署开启采集后，点「检查信源更新」即可收集；自动分析关闭时，收集不会启动模型。

看英文资料的译文

在英文资料详情展开「查看中文译文」。点「AI 翻译成中文」会使用一次模型任务，生成后再次查看会复用已保存的译文。若只收录了订阅摘要，译文也只覆盖摘要。引用时回到英文原文核对。

写稿、排版与导出

  1. 进入「公众号草稿」，选 1–3 篇有原文证据的研究卡，填写作角度。用「整理素材稿」汇总，消耗 0 次模型额度。也可以点「AI 写作」安排一次任务。
  2. 改标题和正文，标清来源转述、我的解读、行动建议，点「保存并更新预览」。如果别的窗口已保存新版本，先保留本页需要的文字，再重新载入并合并。
  3. 切换「纯文字版」或「图文版」，主题可选「清爽白纸」和「深色卡片」。选「复制文字版排版」或「下载两版素材包」。包内有 TXT、Markdown、两版 HTML 和图文使用的 PNG。
  4. 在微信公众平台粘贴正文，按图文版的位置上传本地 PNG，手机预览确认后由你发布。发出后可在研究台手动标为「已发布」。

模型额度与排查

本机上限为滚动 24 小时共 5 次。研究分析、英文翻译和公众号写作共用，失败、超时和结果未知的请求也计入。

阅读、笔记、整理素材稿、保存、换主题、复制和下载均不消耗模型额度。用完全相同的资料、角度和配置再次提交写作，会复用原稿及人工修改。

备份与停止

资料库默认在运行目录的 .data。在 fde-workbench 目录用 Node 24 环境运行 npm.cmd run backup，将资料、草稿、私人笔记和用量回执备份到资料目录下的 backups。

保存当前编辑后，在研究台运行窗口按 Ctrl + C 停止。只关浏览器标签页，研究台会继续运行。
